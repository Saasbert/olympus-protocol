# Olympus Protocol

A 2D side-scrolling one-on-one mech fighter PWA. Command skyscraper-sized robots in head-to-head combat.

**Tech Stack:** Phaser 3 + React + TypeScript + Vite + Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```
