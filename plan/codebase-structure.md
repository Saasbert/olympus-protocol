## Conventions

| Aspect | Convention |
|---|---|
| Naming (files) | camelCase for TS/TSX files |
| Naming (components) | PascalCase React components |
| Naming (Phaser classes) | PascalCase entity/system classes |
| Naming (stores) | camelCase, suffixed with `Store` |
| Naming (data files) | camelCase, singular (`weapon.ts` not `weapons.ts`) |
| Exports | Named exports everywhere (no default exports) |
| Imports | Absolute imports using `@/` alias pointing to `src/` |
| Types | Co-located with usage, exported if shared |
| Styling | Tailwind utility classes for React; inline Phaser styles for canvas |
| State | Zustand stores for cross-framework state; local useState for component-only state |
